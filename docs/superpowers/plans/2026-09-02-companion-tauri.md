**Goal:** A signed macOS app that installs BepInEx + the VDGS mod into the Mac VelociDrone, fetches captures and tracks from the catalog, and launches the game with Doorstop injected — the same four clicks the Windows companion gives.

**Architecture:** Tauri 2 app under `companion-tauri/`. The React page is the existing `web/companion.html`; `web/src/bridge.ts` gains a Tauri transport beside the WebView2 one. The Rust side mirrors the C# companion module for module (`catalog`, `game`, `bepinex`, `tracks`, `launch`, `state`), each behaviour copied from the named C# lines. Every command runs off the UI thread and ends by pushing a fresh `state`; long jobs push `busy` / `progress` first.

**Tech Stack:** Tauri 2 (`tauri`, `tauri-plugin-dialog`), `serde`/`serde_json`, `reqwest` (blocking, rustls), `sha2`, `zip`, `rusqlite` (bundled), `pelite` (reads the .NET DLL's file version), `sysinfo`, `dirs`. Frontend: the existing `web/` Vite project (bun).

**Spec:** `docs/superpowers/specs/2026-09-02-companion-tauri-design.md`. The C# companion (`companion/*.cs`) is the behavioural reference; line numbers below point into it.

## Global Constraints

- Bundle identifier `sh.saqoo.vdgs.companion`; product name `VDGS Companion`; window title `VDGS Companion`.
- Game path in state = the `.app` path. Every file the mod uses lives under its **parent** (`root = game.parent()`), e.g. `root/BepInEx`, `root/vdgs`, `root/libdoorstop.dylib`.
- BepInEx source: `https://github.com/Saqoosha/BepInEx/releases/download/v5.4.23.5-vdgs.1/BepInEx_macos_universal_5.4.23.5-vdgs.1.zip`, 660321 bytes, SHA256 `950d55271c176c732fc896bcdae2750978ef92b940c951aa7fad0eb4251f1d61`.
- Catalog default `https://vdgs.saqoo.sh/catalog.json`, User-Agent `VDGSCompanion`, https only (http allowed on loopback only).
- `launchArgs` in state is `""` on macOS (no `-force-d3d12`).
- Track DB: `~/Library/Application Support/com.velocidrone.velocidrone/user11.db`. Copy before every write. Never overwrite a same-named track. Never delete a row with `online_id != 0 || protected_track != 0`.
- The `bridge.ts` contract (commands `refresh pick installMod uninstallMod removeTrack refreshCatalog get installCapture addTrack fly`; pushes `state log progress busy running`) does not change. `SetupState` shape is `web/src/types.ts:55-74`.
- Never write outside `root` when extracting an archive; refuse entries that escape.
- All Rust modules have unit tests where the plan gives them; run with `cargo test` in `companion-tauri/src-tauri`.
- Commit messages in English, imperative, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Commit only when a task's step says so.

```ts
type TauriGlobal = {
  core: { invoke: (cmd: string, args?: Record<string, unknown>) => Promise<unknown> }
  event: {
    listen: (name: string, fn: (e: { payload: Push }) => void) => Promise<() => void>
  }
}

const webview: WebViewHost | undefined = (
  window as unknown as { chrome?: { webview?: WebViewHost } }
).chrome?.webview
const tauri: TauriGlobal | undefined = (window as unknown as { __TAURI__?: TauriGlobal }).__TAURI__

export const hosted = !!webview || !!tauri

export function send(cmd: Command, id?: string): void {
  if (tauri) void tauri.core.invoke('dispatch', { cmd, id: id ?? null })
  else if (webview) webview.postMessage({ cmd, id })
  else devSend(cmd, id)
}

export function subscribe(fn: (m: Push) => void): () => void {
  if (tauri) {
    let off: (() => void) | null = null
    let gone = false
    void tauri.event.listen('push', (e) => fn(e.payload)).then((u) => { if (gone) u(); else off = u })
    return () => { gone = true; off?.() }
  }
  if (!webview) return devSubscribe(fn)
  const listener = (e: { data: Push }) => fn(e.data)
  webview.addEventListener('message', listener)
  return () => webview.removeEventListener('message', listener)
}
```
